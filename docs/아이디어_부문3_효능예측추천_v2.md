## 1. 문제 진단 (현 뱅크 실태 기반)

### P1. 효능 데이터는 쌓였는데 분양으로 이어지지 않는다
- 목적형 효능 뱅크에는 시험 등급이 붙은 추출물이 화장품 소재 6,015건, 항균·항염·항암·항바이러스 6,189건, 대사질환 600건 있다.
- 누적 분양은 **화장품소재 뱅크 7건(31점), 항생제소재 뱅크 4건(4점)**이다. 일반 추출물 뱅크는 1,098건이다. (MBRIS 자원분양 현황, 2026-10-12 조회)
- 전체 분양 3,153건 중 **기업은 419건(13%)**이고, 학교가 2,120건(67%)이다. 산업화 수요자의 이용이 낮다.

### P2. 이용자가 '무엇을 받을지' 판단할 근거가 없다
- 현재 검색은 '이미 시험된 등급으로 걸러보기'만 된다. **시험되지 않은 자원에는 효능 정보가 전혀 없다.**
  - 해양미생물 바이오뱅크 10,516주 중 효능 시험된 종에 속하지 않는 균주가 **4,610주**(분양 가능 4,525주)다.
  - 미세조류는 256주가 같은 상태다.
- 기업용 플랫폼(Mbio-Bridge)도 마찬가지다. '해양바이오 주요소재 DB'는 6건뿐이고, 전부 '샘플 데이터 1~6'이라는 이름이다. '기업수요 매칭'은 담당자가 답변하는 온라인 상담 방식이다. MBRIS의 효능 데이터와 기업용 창구가 **끊겨 있다.**

### P3. 분양 한도와 소요 기간 때문에 '잘못 고른 비용'이 크다
- 분양 한도(분양 안내): 미생물은 회당 20점·**연간 50점**, 추출물은 회당 20점·연간 100점이다.
- 소요 기간: 자원 확인 7일 + 신청서 검토 7일 + 승인 2~3일이다. 배양체는 7~15일이 더 걸린다. **한 번 고르는 데 약 3~5주**가 든다.
- 무작위로 고르면 연간 한도 50주로 기대할 수 있는 항균(S. aureus) A등급은 **0.4건**이다(미생물 추출물 A율 0.9%, 2장 참조). 기업에게 "받아봐야 소용없는" 구조다.

### P4. 성과가 돌아오지 않아 개선이 쌓이지 않는다
- 분양 후 6개월이 지나면 성과보고서를 내는 것이 의무다(분양 안내). 그런데 뱅크 '성과현황' 공개 게시판은 **0건**이다.
- 어떤 자원이 성과로 이어졌는지에 대한 공개 데이터가 없다. 그래서 다음 이용자의 선택에도, 뱅크의 시험·확보 우선순위에도 반영되지 않는다.

> **원인 요약:** 데이터(효능 등급)는 있지만 ① 미시험 자원으로 확장되지 않고, ② 이용자의 목적과 연결되지 않으며, ③ 결과가 돌아오지 않는다.

## 2. 현황 분석 및 벤치마킹

### 2-1. 뱅크 데이터 분석 (직접 수행)

**(a) 효능은 계통에 몰려 있다.** 추출물 30건 이상, 3종 이상인 계통만 집계했다.

| 계통 | 효능 (A 비율 / 평균 대비) |
|---|---|
| 다시마목 (감태·곰피·대황) | ABTS 89% (×7), Collagenase 53% (×7), S. aureus 45% (×9) |
| 모자반속 / 갈조강 | NO 54% (×4), S. aureus 31% (×6) |
| 그물바탕말목 | PGE2 72% (×6.5) |
| 사초과 (좀보리사초 등) | PGE2 72% (×6.6) |
| 장미목 (해당화 등) | ABTS 97% (×7.6) |
| 방선균 *Streptomyces* (37종) | S. aureus 19% (미생물 평균의 ×23) |

**(b) 계통만으로 처음 보는 종의 효능을 예측할 수 있다.** 학습에 없던 종을 맞히는 조건(종 단위 5겹 교차검증)이다.

| 시험 | AUC | 비고 |
|---|---|---|
| S. aureus 항균 | 0.92 | |
| PGE2 항염 | 0.91 | |
| DPPH 항산화 | 0.91 | |
| NO 항염 | 0.87 | |
| Collagenase | 0.85 | |
| 26개 시험 평균 | 0.76 | |
| 항바이러스(H1N1, A형간염) | 0.64, 0.57 | **예측 불가 → 서비스에서 표시하지 않음** |

- **목 수준까지만 알아도 성능 대부분이 나온다.** 예: S. aureus는 대분류 0.84 → 목 0.90 → 속 0.92. 그래서 종 동정이 불완전한 자원에도 적용할 수 있다.

**(c) 연간 분양 한도(미생물 50점)에서의 효과.** 미생물 추출물만 대상이고, 종 단위 분리 검증 결과다.

| 목표 효능 | 무작위 50주 기대 A | 예측 상위 50주 실제 A | 배수 |

### 2-2. 벤치마킹과 우리 뱅크에 적용하는 방식

| 사례 | 내용 | 우리 뱅크 적용 |
|---|---|---|
| 계통 기반 유용식물 예측 (Saslis-Lagoudakis et al., PNAS 2012) | 약 2만 종 계통수에서 약용식물이 특정 가지('hot node')에 몰림. 약용식물이 무작위보다 60% 많고, 같은 질환군으로 좁히면 133% 많음. 한 지역의 hot node로 다른 지역을 예측 | 뱅크 효능 등급으로 '해양 hot node'를 직접 산출(2-1a). 이를 검색·추천에 쓴다 |
| BacDive (독일 DSMZ) | 약 10만 균주의 표준화된 표현형 데이터를 통합·검색·API로 제공 | 뱅크 균주 정보에 '효능 가능성' 표현형 층을 더한다. API로 외부(기업·K-BDS)와 연동한다 |
| NCI 천연물 분획 라이브러리 (NPNPD, 미국) | 2019년부터 분획 50만 점 이상을 연구자에게 무상 제공. '고르기 쉬운 형태'로 표준화 | 뱅크도 무상 분양 체계다. 무엇을 고를지 안내하는 층이 없는 것이 차이 → 예측·추천으로 보완 |
| 국립호남권생물자원관 AI 후보물질 선별 (2026-10 보도) | 섬·연안 식물의 후보물질·유전자 우선순위를 연구용으로 매김 | 본 제안은 **분양 서비스와 직결**한다(검색 표시·한도 내 추천·성과 환류). 해양 효능 시험 1.3만 건을 라벨로 쓴다 |

**도출 방향:** 국내외 선진 사례는 ① 표준화된 데이터를 ② 이용자가 고르기 쉬운 형태로 제공하고 ③ 외부와 연동한다. 우리 뱅크는 ①을 이미 갖췄다(효능 등급). ②·③이 비어 있다.

## 3. 개선 방안 및 적용 계획

### 3-1. 서비스 구성: '효능 내비게이터'

| 모듈 | 무엇을 하나 | 해결하는 문제 |
|---|---|---|
| ① 효능 가능성 표시 | 검색 결과의 모든 자원에 시험별 표시를 붙인다. 시험된 자원은 '실측 A/B/C', 시험 안 된 자원은 '예측 가능성(높음·보통·낮음)' + 근거 계통 + 같은 계통의 시험 건수. **실측과 예측은 색·문구로 구분**하고, 근거가 부족한 계통은 표시하지 않는다(같은 계통 시험 종 3종 이상, 추출물 10건 이상일 때만) | P2 |
| ② 목적 기반 추천 | "그람양성 항균, 미생물, 20점"처럼 목적과 수량을 넣으면 분양 한도 안에서 기대 적중이 가장 높고 계통이 겹치지 않는 후보 목록을 준다. 장바구니로 바로 연결 | P1·P3 |
| ③ 기업 창구 연동 | Mbio-Bridge 소재 DB를 '계통–효능 지도'로 자동 채우고, 수요매칭 상담에 추천 리포트를 첨부한다 | P2 |
| ④ 성과·시험 환류 | 성과보고서에 '효능 확인 결과(있음/없음)' 항목 1개를 추가하고, 뱅크 신규 시험 결과와 함께 월 1회 재학습한다. 뱅크 내부에는 '다음에 시험할 자원' 우선순위를 제공한다 | P4 |

### 3-2. 단계별 로드맵

| 단계 | 기간 | 내용 | 수행 주체(역할) |
|---|---|---|---|
| 0. 파일럿 | 완료 | 공개 데이터로 모델·검증 (2-1) | 제안팀 |
| 1. 데이터 정비 | 1~3개월 | 뱅크 간 중복 번호 통합, 분류 보정(NCBI·WoRMS), 성과보고서 항목 추가 | 뱅크 운영 부서 + 위탁 기관 |
| 2. 시범 서비스 | 4~6개월 | 미생물 뱅크 + 효능 뱅크에 ①·② 적용. 항균·항염만 표시 | 위탁 개발 기관 |
| 3. 효과 검증 | 7~12개월 | 추천 경유 분양과 일반 분양의 성과·만족도 비교. 뱅크 시험 우선순위로 신규 시험 진행 | 뱅크 운영 부서 |
| 4. 확대 | 2년 차 | ③ Mbio-Bridge 연동, 외부 API, 멀티모달 확장(균주 마커유전자 서열, 채집 환경) | 뱅크 + 협력 기관 |

### 3-3. 한계와 대응 (예산·인력·법·신뢰)
- **예산·인프라:**
  - 모델이 가볍다(계통 정보 + 로지스틱 회귀). GPU가 필요 없고, 기존 서버에서 일·월 단위로 갱신하면 된다.
  - 데이터는 이미 뱅크가 보유한 것과 공개 데이터만 쓴다. 신규 비용은 주로 검색 화면 개발과 데이터 정비 위탁이다. 기존 MBRIS 유지보수 범위 안에서 기능을 추가하는 수준이다.
- **인력:** 데이터 담당 1인이 월 1회 재학습을 맡는다(자동화 스크립트 제공).
- **법·제도:**
  - 예측 정보는 분양 승인 절차(해양수산생명자원법 시행령 제17조)와 무관한 '참고 정보'다. 승인 기준을 바꾸지 않는다.
  - 성과보고서 항목 추가는 기존 의무 제출 양식 안에서 할 수 있다.
- **신뢰·오인:**
  - 실측과 예측을 시각적으로 구분하고, 근거가 부족한 계통과 예측력이 낮은 시험(항바이러스 등)은 표시하지 않는다.
  - 예측 성능(AUC, 적중률)을 매월 공개한다.
- **알려진 한계:** 효능 등급이 3단계이고 in vitro 결과다. 같은 종도 채집 시기에 따라 등급이 달라지는데, 이 부분은 4단계에서 채집 환경 정보를 붙여 보완한다.

## 4. 기대효과 및 파급력

### 유용성 (뱅크 운영)
- **분양 적중률:** 연간 미생물 50점 한도에서 항균 A등급 기대치가 **0.4건 → 6~7건(×13~26)**, 항염은 **1.4건 → 8건(×6)**이다(산출 근거: 2-1c, 종 단위 분리 검증).
- **사장된 데이터 활용:** 화장품·항생제 소재 뱅크(1.2만 건)의 시험 결과가 '미시험 4,525주'의 선택 근거로 확장된다.
- **기업 이용 확대:** 기업의 첫 진입 장벽(무엇을 받아야 하나)을 낮춘다. 목표 지표: 기업 분양 비중 13% → 3년 내 20%(가설, 3단계에서 측정).
- **행정 효율:**
  - 반복 상담(무엇을 추천하느냐)을 추천 리포트로 대체한다.
  - 뱅크 내부 시험 순서를 근거 기반으로 정한다. 같은 수의 A등급을 찾는 데 필요한 시험이 항균 기준 최대 약 1/13~1/26로 준다.

### 파급력
- **지속성:** 성과보고와 신규 시험이 쌓일수록 예측이 좋아지는 환류 구조다. 한 번 만들고 끝나는 기능이 아니다.
- **확산:**
  - 같은 방법을 국가 생물자원 책임기관(자생·담수·극지 등)에 적용할 수 있다.
  - 국가 바이오데이터 플랫폼(K-BDS, 2030년까지 700만 건 목표)과 API로 연동할 수 있다.
  - Mbio-Bridge 기업 지원(공동연구·특허 개방)과 결합할 수 있다.
- **멀티모달 확장:** 균주 마커유전자 서열(DNA 언어모델), 채집 위치·시기(위성 수온·엽록소), 현장 사진을 붙이면 계통으로 설명이 안 되는 효능(계절 변동, 항바이러스)까지 다룰 수 있다.
- **정책 부합:** 국감 지적(해양바이오 과제 31건 중 상용화 7건, 소재 DB 고도화 필요)과 정부의 'AI로 유용 바이오 소재 선제 발굴' 방향에 맞다.

## 7. 리스크 및 제출 전 확인

- [ ] **기존 서비스와 동일 여부:** '기업수요 매칭'은 상담 방식이고, '주요소재 DB'는 샘플 6건이며, MBRIS 검색은 등급 필터만 있다. 예측·추천 기능은 없음을 확인했다(2026-10-12). 제출 직전에 한 번 더 확인하고 캡처를 파일3에 넣는다.

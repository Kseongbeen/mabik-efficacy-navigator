**한줄요약** (100자 이내)

## 1. 문제 진단

□ 효능 시험 결과는 쌓여 있으나 분양으로 이어지지 않음
 ○ 목적형 효능 뱅크는 추출물 1만 2,804건에 효능 등급을 부여하여 공개 중
  - 화장품소재 6,015건 / 항균·항암·항바이러스 6,189건 / 대사질환 600건
 ○ 누적 분양 실적은 화장품소재 뱅크 7건과 항생제소재 뱅크 4건에 그침 (MBRIS 자원분양 현황)
 ○ 전체 분양 3,153건 가운데 기업 분양은 419건으로 13% 수준이며 산업화 수요자의 이용이 저조함

□ 미시험 자원은 효능을 판단할 정보가 전혀 없음
 ○ 현재 검색은 이미 시험된 자원을 등급으로 거르는 기능만 제공
 ○ 해양미생물 바이오뱅크 1만 516주 가운데 4,610주는 효능 시험이 이루어진 종에 속하지 않음
 ○ 이 중 4,525주가 분양 가능 상태이나 이용자는 학명과 채집지 정보만으로 선택해야 함
 ○ 기업용 창구인 Mbio-Bridge의 해양바이오 주요소재 DB는 6건이며 모두 샘플 데이터로 표시됨
 ○ 기업수요 매칭은 담당자 상담 방식으로 운영되어 효능 데이터와 직접 연결되지 않음

□ 분양 한도와 소요 기간 때문에 잘못 고른 비용이 큼
 ○ 미생물 분양은 회당 20점이고 연간 50점으로 제한됨 (분양 안내)
 ○ 자원 확인과 검토와 승인에 약 3주가 걸리고 배양체는 7~15일이 추가됨
 ○ 미생물 추출물 가운데 황색포도상구균 항균 A등급 비율은 0.9%임
 ○ 연간 한도 50주를 임의로 고르면 기대 A등급 수는 0.4건에 불과함

□ 성과가 다음 선택으로 돌아오지 않음
 ○ 분양 후 6개월이 지나면 성과보고서 제출이 의무이나 성과현황 공개 게시판은 0건임
 ○ 어떤 자원이 성과로 이어졌는지 이용자와 뱅크 모두 참고할 수 없음

□ 원인 정리
 ○ 효능 데이터가 미시험 자원으로 확장되지 않음
 ○ 이용자의 목적과 자원이 연결되지 않음
 ○ 분양 이후 결과가 데이터로 축적되지 않음

## 2. 현황 분석 및 벤치마킹

□ 뱅크 효능 데이터 분석 결과 효능은 생물 계통을 따라 모여 있음
 ○ 같은 계통의 생물은 같은 생합성 경로를 공유하여 비슷한 물질을 만드는 경향이 있음
 ○ 효능 뱅크 1만 2,804건을 계통별로 묶어 A등급 비율을 비교함 (추출물 30건 이상이고 3종 이상인 계통만 집계)

|---|---|---|---|
| 다시마목 (감태·곰피·대황) | 항산화 ABTS | 89% | 7배 |

□ 계통 정보만으로 처음 보는 종의 효능을 상당 수준 예측할 수 있음
 ○ 학습에 쓰지 않은 종을 맞히는 방식으로 검증함 (종 단위 5겹 교차검증)
 ○ 예측 정확도(AUC)는 황색포도상구균 항균 0.92 / 항염 PGE2 0.91 / 항산화 DPPH 0.90 / 26개 시험 평균 0.76임
 ○ 목 수준의 계통만 알아도 대부분의 성능이 확보되어 종 동정이 불완전한 자원에도 적용 가능함
 ○ 항바이러스 시험은 0.58~0.64로 예측력이 낮아 서비스 표시 대상에서 제외함

|---|---|---|

| BacDive (독일 DSMZ) | 약 10만 균주의 표준화된 표현형 정보를 통합 검색과 API로 제공 | 뱅크 균주 정보에 효능 가능성 정보를 더하고 외부 플랫폼과 연동 |
| 천연물 분획 라이브러리 (미국 NCI) | 2019년부터 50만 점 이상의 천연물 분획을 연구자에게 무상 제공 | 뱅크도 무상 분양 체계를 갖추었으나 무엇을 고를지 안내하는 기능이 없어 이를 보완 |
| 섬·연안 생물 후보물질 선별 시스템 (국립호남권생물자원관 2026) | 섬·연안 식물의 후보물질과 유전자 우선순위를 연구용으로 산출 | 본 제안은 분양 검색과 추천과 성과 환류에 직접 연결된다는 점에서 차별됨 |

□ 개선 방향
 ○ 선진 사례는 표준화된 데이터를 이용자가 고르기 쉬운 형태로 제공하고 외부와 연동하는 공통점이 있음
 ○ 우리 뱅크는 표준화된 효능 데이터를 이미 갖추었으므로 선택 지원과 연동 기능을 더하는 것이 효과적임

## 3. 개선 방안 및 적용 계획

□ 서비스 구성 (효능 내비게이터)

[그림 4 삽입: 그림/그림4_서비스구조.png]

| 기능 | 내용 | 해결 문제 |
|---|---|---|
| ① 효능 가능성 표시 | 검색 결과의 모든 자원에 시험별 효능 정보를 표시함. 시험된 자원은 실측 등급을 표시하고 미시험 자원은 예측 가능성(높음·보통·낮음)과 근거 계통을 표시함 | 미시험 자원 정보 부재 |
| ② 목적별 추천 | 목적 효능과 자원 유형과 수량을 입력하면 분양 한도 안에서 기대 성과가 높은 후보를 제시하고 장바구니로 연결함 | 근거 없는 선택과 한도 낭비 |
| ③ 기업 창구 연동 | Mbio-Bridge 주요소재 DB를 계통별 효능 정보로 채우고 수요매칭 상담에 추천 결과를 첨부함 | 기업 창구와 효능 데이터 단절 |
| ④ 성과·시험 환류 | 성과보고서에 효능 확인 여부 항목을 추가하고 신규 시험 결과와 함께 월 1회 예측을 갱신함. 뱅크 내부에는 다음 시험 대상 우선순위를 제공함 | 성과 미축적 |

□ 오인 방지 원칙
 ○ 실측 등급과 예측 정보는 색과 문구를 달리하여 구분함
 ○ 같은 계통에서 시험된 종이 3종 미만이거나 추출물이 10건 미만이면 예측을 표시하지 않음
 ○ 예측력이 낮은 시험(항바이러스 등)은 표시하지 않음
 ○ 예측 성능을 정기적으로 공개함

□ 단계별 추진 계획

| 단계 | 기간 | 주요 내용 | 수행 주체 |
|---|---|---|---|
| 1단계 데이터 정비 | 1~3개월 | 뱅크 간 중복 자원번호 통합과 분류 정보 보완 / 성과보고서 항목 추가 | 뱅크 운영 부서, 위탁 기관 |
| 2단계 시범 운영 | 4~6개월 | 미생물 뱅크와 효능 뱅크에 ①② 기능 적용 / 항균·항염 시험부터 표시 | 위탁 개발 기관 |
| 3단계 효과 검증 | 7~12개월 | 추천 경유 분양과 일반 분양의 성과와 만족도 비교 / 우선순위에 따른 신규 시험 | 뱅크 운영 부서 |
| 4단계 확대 | 2년 차 | Mbio-Bridge 연동과 외부 API 제공 / 균주 유전자 서열과 채집 환경 정보를 더한 예측 고도화 | 뱅크, 협력 기관 |

□ 예상 한계와 대응
 ○ 예산과 설비
  - 예측 모델은 계통 정보만 사용하는 경량 구조로 별도 고성능 장비 없이 기존 서버에서 운영 가능함
  - 뱅크 보유 데이터와 공개 데이터만 사용하므로 데이터 구매 비용이 없음
  - 신규 비용은 검색 화면 개발과 데이터 정비 위탁이 중심이며 기존 시스템 유지보수 범위 안의 기능 추가 수준임
 ○ 인력
  - 데이터 담당 1인이 월 1회 갱신을 수행하도록 자동화 절차를 함께 제공함
 ○ 법·제도
  - 예측 정보는 참고 정보로만 제공하며 분양 승인 기준(해양수산생명자원법 시행령 제17조)에는 영향을 주지 않음
  - 성과보고서 항목 추가는 기존 의무 제출 양식 안에서 가능함
 ○ 데이터 한계
  - 효능 등급이 3단계이고 시험관 내 결과라는 한계가 있음
  - 같은 종도 채집 시기에 따라 등급이 달라지는 사례가 있어 4단계에서 채집 환경 정보를 더해 보완함

## 4. 기대효과 및 파급력

□ 유용성
 ○ 분양 성과 향상
  - 연간 미생물 한도 50주 기준 항균 A등급 기대치가 0.4건에서 6~7건으로 늘어남 (2항 모의 비교 결과)
  - 항염 A등급 기대치는 1.4건에서 8건으로 늘어남
 ○ 보유 데이터의 가치 확대
  - 화장품·항생제 소재 뱅크 8,800여 건의 시험 결과가 미시험 분양 가능 자원 4,525주의 선택 근거로 쓰임
 ○ 기업 이용 확대
  - 무엇을 분양받아야 하는지에 대한 진입 장벽을 낮춤
  - 기업 분양 비중 13%를 3년 안에 20%로 높이는 것을 목표로 하며 3단계에서 실제 효과를 측정함
 ○ 행정 효율
  - 반복되는 추천 상담을 추천 결과 제공으로 대체함
  - 뱅크 내부 시험 순서를 근거에 따라 정하여 같은 수의 A등급 자원을 찾는 데 필요한 시험 수를 줄임

□ 파급력
 ○ 지속성
  - 성과보고와 신규 시험이 쌓일수록 예측이 정교해지는 순환 구조임
 ○ 확산 가능성
  - 같은 방식을 다른 국가 생물자원 책임기관에 적용할 수 있음

  - Mbio-Bridge의 공동연구 신청과 미활용 특허 나눔 사업과 연계하여 기술사업화를 지원함
